ADR-004 — Gate données

Statut : accepté · 18/10/2026

Toute migration destructive doit être accompagnée d'une sauvegarde vérifiée et d'une procédure de restauration testée. Le gate data bloque la fusion tant que la preuve n'est pas présente.

Conséquences : les migrations sont découpées en expand/contract ; le temps de déploiement augmente d'un cycle.

Principes de conception

Dépôt = source de vérité. Markdown, JSON, JSONL. Pas d'état dans un service.

CLI = point d'application. Tout obligatoire est vérifiable par sdlc check.

Hooks et plugins optionnels. Jamais le seul lieu d'une règle.

Adaptateurs minces. Permissions et invocation, pas de logique métier.

Fonctions déterministes outillées. Un script testable sans agent ; la skill orchestre.

Sorties standard. JUnit, SARIF, Cobertura, JSON — lisibles par tous.
